e-Invoices AISB · Kept in SQL Account

Printed invoice

What opens when you press a PDF in the Print column of e-Invoices: a customer invoice, debit note or credit note, or a self-billed invoice, laid out as SQL Account prints it, on US Letter. The same document goes into the month's zip, made by All of the month.

The layout is SQL's own and is not restyled. Every text sits where SQL prints it, in SQL's fonts and sizes, so a printed copy matches what SQL Account produces. Only the frame around the page and the notes beside it belong to this app: nothing on the paper follows this app's look. A line too long for its place shrinks to half SQL's size, and past that its end is cut off and the cut is noted.

Fonts

Fonts: SQL's font Tahoma (most of the invoice's words) isn't on this computer (or its file is damaged), so invoices print it in DejaVu Sans, a free look-alike on this computer, never larger than SQL's size.

SQL's font Tahoma Bold (the title, the document number and Total) isn't on this computer (or its file is damaged), so invoices print it in DejaVu Sans Bold, a free look-alike on this computer, never larger than SQL's size.

To print exactly as SQL does, install tahoma.ttf, tahomabd.ttf on this computer from a Windows computer's Fonts folder, or put licensed copies of them in a folder outside the records folder and name that folder in HRP_FONT_DIR.
